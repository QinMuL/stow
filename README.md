# Stow

自托管的网盘媒体管理工具:把网盘资源整理成规范的媒体库,并把资源卡片推送到 Telegram 频道。

> ⚠️ 仍在开发中:配置项与接口可能变动,功能会持续增补。

## 它能做什么

- **链接推卡**:给 Bot 发 ed2k / 115 分享链接,自动识别作品(TMDB)并生成规范卡片,推送到对应归属频道
- **转存流水线**:115 分享 → 转存 → 目录标准化(Emby 结构)→ 建永久分享 → 审核通过后推卡
- **下载上传闭环**:监控网盘目录 → 搬到本地 → 探测 / 按需清洗 / 重命名 / 计算 ed2k → 上传到 115
- **频道监控**:盯住源频道的新消息,自动提取链接走同一条推卡链路
- **Web 配置台**:全局配置分组、流水线实时进度、按段健康判据、系统日志

## 快速开始

1. 拉取仓库,准备好三个本地目录:`config.json`(照 `config.example.json` 填,或先留空)、`data/`、`media/`
2. 启动:

   ```bash
   docker compose up -d
   ```

3. 打开 `http://127.0.0.1:8686`,在配置台里填 Bot Token 等其余配置并保存重启

## 配置项从哪来

| 用途 | 需要准备 |
|---|---|
| Bot 与频道 | Telegram Bot Token、管理员 uid、各归属频道的 chat id |
| 识别与卡片 | TMDB API key |
| 115 相关功能 | 115 Cookie |
| 下载上传闭环 | openlist 地址与令牌、CloudDrive2 地址与令牌 |

没填的段不会启动,配置台会显示"未配置"并在健康判据里标出来。
